# Home Premium Visual Polish Design

## Goal
Raise the AFAAQ ARAB homepage from a clean editorial prototype to a premium corporate engineering presentation while preserving the approved Engineered Editorial direction, the current Home hero photograph, all factual project/service content, and the text-only project portfolio requirement.

## Approved visual problems to solve
- Header brand and navigation lack presence.
- Hero headline rhythm and CTA hierarchy need stronger composition.
- Technical/mono microcopy is too small in several places.
- Power-system proof section is too flat and over-spaced.
- Major Projects still reads like an image-led layout with media removed.
- The remaining-project rail is too small, crowded and dashboard-like.
- Relationship marquee feels generic and visually weak.
- Core Services rows have weak hierarchy and excessive dead space.
- Project Execution reads like a flat table rather than a controlled process.
- About artwork is visually heavier than the editorial system around it.
- Final CTA and footer lack a decisive closing hierarchy.
- Repeated label-heading-rule-column compositions need more section identity and better vertical rhythm.

## Design decisions
1. **Header** — increase brand mark, wordmark and navigation scale; retain sticky behavior, underline state, current IA and mobile navigation behavior.
2. **Hero** — keep the current image-blend photo and copy; rebalance headline width/scale, strengthen body readability and primary CTA weight, and make secondary navigation clearly subordinate.
3. **Typography system** — increase SectionLabel and action text sizes modestly, improve muted contrast, and reduce reliance on extremely small mono text without changing the core IBM Plex Sans/Mono system.
4. **Power proof** — tighten vertical space, strengthen numerals and discipline labels, and give the proof row a more intentional editorial rule system.
5. **Projects** — preserve text-only presentation. Recompose the featured project as a compact case-study ledger and convert the remaining portfolio from a carousel-style strip into a stable responsive project index with stronger project names, relationship marks, voltage labels and scopes. No project images or image placeholders.
6. **Relationships** — keep continuous motion but increase mark/name presence and simplify separators/spacing so it reads as an established client relationship strip rather than a generic ticker.
7. **Services** — make each service row a stronger horizontal editorial unit with larger title/summary, clearer number, compact CTA and controlled hover/focus treatment.
8. **Execution** — keep six factual steps but express sequence through larger step numerals, stronger rules and a visible progression rhythm rather than card UI.
9. **About** — keep approved artwork assets; reduce brochure-like dominance by using the wide artwork on desktop, a restrained frame, and a better text/image ratio.
10. **Final CTA** — tighten composition, increase CTA prominence and align supporting copy with the action.
11. **Footer** — remove the oversized isolated bottom logo, compact the footer, strengthen contact/navigation readability, and close with a small brand/legal row.

## Responsive rules
- 320px remains a supported minimum width.
- Mobile stays text-first with no horizontal overflow.
- Projects become stacked ledger rows/cards on mobile and a 3-column index on larger screens.
- Services and execution retain clear reading order at all breakpoints.
- Tap targets remain at least 48px where interactive.
- Existing reduced-motion behavior remains intact.

## Constraints
- No new project photography.
- Do not change project names, relationships, scope, voltage/system labels, location or year.
- Do not change Home hero photo.
- Do not reintroduce ProjectMedia to project surfaces.
- Avoid generic rounded cards, heavy shadows, gradients used as decoration, or flashy motion.
- Preserve existing accessibility behavior, semantic links and focus states.
